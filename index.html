문제 정의와 해결 방법

문제

음식 사진을 올리면 영양 정보를 조회할 수 있는 서비스를 만들고자 했습니다. 과제 기간과 학습 장비가 제한적이어서 전체 음식 클래스를 학습하기 어려웠습니다.

→
해결

핵심 기능 검증에 필요한 음식 클래스를 선정하고, 사전 학습된 MobileNet에 전이 학습을 적용했습니다.

구현 결과

사진에서 예측한 음식 종류를 공공 영양성분 API에 연결해 영양 정보를 보여주고, LLM 기반 영양 추천 기능을 추가했습니다.

이후 발전 방향

ResNet 등 다양한 모델과 성능·연산량을 비교하고, 클래스 불균형과 대규모 데이터의 효율적인 학습 방법을 적용해 분류 범위를 확장
